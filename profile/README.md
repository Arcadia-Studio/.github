# Arcadia Studio

Productivity tools for Obsidian, built by [Peter J. Carter](https://theologyinfocus.org). One developer, one ecosystem: a free theme plus five plugins that share a common design language. Every plugin has a working free tier; premium tiers fund continued development.

**Store:** [arcadia-studio.lemonsqueezy.com](https://arcadia-studio.lemonsqueezy.com)

## How licensing works

Free tiers work without an account, a license key, or a time limit. Premium features unlock with a license key from the [store](https://arcadia-studio.lemonsqueezy.com), entered in each plugin's settings tab. One developer maintains all of this; premium purchases are what keep it maintained.

## Support and feedback

Open an issue on the relevant repository for bugs and feature requests. All repositories accept issues from free and premium users alike.
